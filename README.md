# Plantation-Planner
Browser-based plantation layout planner: draw any farm shape, set its real area, apply 20 multi-species models, edit plants and rows, and export a shareable layout image. Built with AI assistance.
# What it does
Draw a farm boundary or pick a preset shape, then set its real area (acres, hectares, m², cents or guntas) or one real edge length.
Apply one of 20 multi-species plantation models; each rescales to your boundary.
Edit spacing, layout pattern, zones, markers and individual plants.
Number rows, set row and plant limits, and add Farm ID, farmer name and a note.
Export the layout as an image to share.
# How to use

Open the published page in any modern browser (works on phones). No installation, no data leaves your device.

Notes
Plant counts are indicative and should be checked against local agronomic guidance.
Model layouts are based on the author's own planning slides.
